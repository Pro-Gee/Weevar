# Weevar v1.0 Announcement Template

## Headline

Weevar v1.0 is now publicly available.

## TL;DR

- Dev-only overlay for live UI manipulation
- Structured prompts for AI coding assistants

- Undo/redo/delete session controls
- Overview + prompt trays and copy workflow
