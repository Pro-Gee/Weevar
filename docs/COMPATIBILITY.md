# Compatibility

## Frameworks

- React 17+
- React DOM 17+

## Tooling

- Vite (recommended path via `weevar/vite`)
- SWC and Webpack integrations available through package subpaths

## Browser support

- Primary validation: Chromium-based browsers
- Firefox/Safari: best effort (not yet full parity target)

## Environment

- Development only
- No production runtime behavior by design
